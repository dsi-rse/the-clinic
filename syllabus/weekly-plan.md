# Weekly Plan
The following is a general guide to the weekly responsibilities of students, TAs and mentors. All specific dates can be found on Canvas.

## Every Week

From the first mentor session onward, the same cycle repeats every week. It runs from one mentor session to the next and is tracked in GitHub.

<table border="1" cellpadding="5" cellspacing="0">
    <thead>
        <tr>
            <th>When</th>
            <th>Who</th>
            <th>What</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Mentor session</td>
            <td>Mentor</td>
            <td>Run the meeting, hear each student's update, assign next week's tasks with clear acceptance criteria</td>
        </tr>
        <tr>
            <td>Midnight, day of the mentor session</td>
            <td>Students</td>
            <td>Open GitHub issues for next week's tasks with acceptance criteria; post links in the Slack thread</td>
        </tr>
        <tr>
            <td>During the week</td>
            <td>Students</td>
            <td>Attend both TA sessions, make steady progress, push code to a pull request, respond to TA code reviews</td>
        </tr>
        <tr>
            <td>During the week</td>
            <td>TA</td>
            <td>Run two TA sessions; review pull requests with <code>/clinic-pr-review</code>; confirm students are pushing and opening issues; unblock technical problems; post a weekly update per project to the clinic TAs Slack thread</td>
        </tr>
        <tr>
            <td>Midnight, day before the mentor session</td>
            <td>Students</td>
            <td>Work submitted in a pull request; weekly report posted as a comment on each issue; links posted in the Slack thread; short update prepared</td>
        </tr>
        <tr>
            <td>Before the mentor session</td>
            <td>Mentor</td>
            <td>Run <code>/clinic-project-review</code>, review student work, grade the weekly tasks (0-5) and weekly report (0-5), escalate anything that needs it</td>
        </tr>
    </tbody>
</table>

Formats and grading: [weekly tasks template](../templates/weekly-tasks.md), [weekly report template](../templates/weekly-report.md), [weekly tasks rubric](../rubrics/weekly-tasks-rubric.md), [weekly report rubric](../rubrics/weekly-report-rubric.md).
