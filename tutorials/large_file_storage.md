## Large file storage

Do not store any files larger than 10 MB in the repository, and try to avoid files larger than 1 MB. Put these and all data files in a [UChicago Box folder](https://uchicago.account.box.com).

For how to install Box Drive so that code and Docker can read your Box files, see [Computer Setup, section 8](./clinic-computer-setup.md#8-box). Windows users have extra setup to do, covered in [Box on Windows (WSL)](./box-wsl.md).
